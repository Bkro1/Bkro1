# `featured`

## 🌍 EconIQ

### Economic Intelligence for Africa

**EconIQ** is the project I'm currently putting most of my energy into.

The idea is simple:

> **Make economic data easier to understand and easier to use.**

I'm building it around economic datasets, machine learning, analytics and RAG so that users can explore economic trends and ask questions about the data in a more natural way.

### Under the hood

`Economic Data → Data Processing → Analytics → Machine Learning → RAG → Economic Q&A`

### Built with

`Python` `SQL` `FastAPI` `Next.js` `TypeScript` `scikit-learn` `PostgreSQL` `Qdrant` `Docker`
